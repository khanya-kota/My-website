# Green Roots Organics Website

## 1. Project Overview

Green Roots Organics is a South African organic fruit and vegetable delivery service. The business was founded in 2018 in Port Elizabeth by two local farmers.

This website provides customers with information about the company, its products and services, organic farming, subscriptions, healthy living and customer enquiries. The design aims to create a natural, fresh, trustworthy and user-friendly online experience.

### Website Goals

- Increase online orders and subscription sign-ups.
- Generate leads through newsletter sign-ups and enquiry forms.
- Provide information about organic farming and healthy living.
- Build customer trust through product information and company content.
- Provide an easy and convenient online shopping experience.

The website aims to increase online orders and subscription sign-ups by 40% within six months.

### Target Audience

- Health-conscious families aged 25–50.
- Working professionals.
- Small cafés and restaurants.
- Customers who value organic and locally grown produce.
- Customers who prefer convenient home delivery.

## 3. Part 1: HTML Files

Part 1 contains the HTML structure of the Green Roots Organics website. Each HTML file is responsible for the content and layout of a specific page.

### Project HTML Files

| HTML File | Description |
|---|---|
| `index.html` | The homepage introduces Green Roots Organics, displays the hero section, featured products, testimonials and links to the other pages. |
| `Pages/about.html` | Provides the company history, mission, vision, farm information and company values. |
| `Pages/context.html` | Provides information about organic living, healthy eating, sustainability, products and services. |
| `Pages/descriptive.html` | Describes the products, produce categories, subscription boxes and services offered by the business. |
| `Pages/enquiry.html` | Provides contact information and an enquiry form for customers. |

### HTML Structure and Features

- HTML5 document structure.
- Semantic elements such as `header`, `nav`, `main`, `section`, `article` and `footer`.
- Navigation links between all website pages.
- Headings, paragraphs, lists and content sections.
- Product cards and information boxes.
- Forms and form controls on the enquiry page.
- Comments explaining the HTML syntax and purpose of the code.
- Shared CSS stylesheet linked to every HTML page.
